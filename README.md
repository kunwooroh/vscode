# 젬마 비서 (Gemma Agent)

Gemma 4를 **폰 안에서만** 실행하는 개인 AI 에이전트 안드로이드 앱입니다. 인터넷은 모델을 처음 내려받을 때만 씁니다.

## 기능
- 🎙️ **음성 비서 모드**: 가운데 빛나는 원을 누르고 말하면 → 알아듣고 → 목소리와 글자로 함께 대답 → 다시 귀를 기울임 (핸즈프리)
  - 말을 멈추면 자동으로 알아듣기, 말하는 도중 원을 누르면 끊고 바로 듣기
  - "그만", "고마워"라고 하면 대기 상태로
  - 앱을 열면 인사와 함께 남은 할 일 수를 알려줌
- 채팅 (한국어 개인비서: 요약, 번역, 초안, 아이디어, 일정 정리)
- 🎤 듣기: 폰 한국어 음성인식으로 정확하게 받아 적어 Gemma에 전달 (실시간 자막). 설정에서 'Gemma 직접 듣기'로도 바꿀 수 있음
- 🗣️ 목소리: **Supertonic 3** (2026 최신 무료 온디바이스, 여성 5·남성 5, 두 목소리 섞기, 속도·음질) 또는 폰 기본 음성(삼성·구글 엔진의 모든 한국어 목소리, 높낮이·속도)
- 🖼️ 사진 첨부: 사진을 보고 설명하거나 질문에 답변
- 🛠️ 에이전트 도구 (모델이 스스로 실행)
  - 할 일 추가·목록·완료·삭제
  - N분/N시간 뒤 알림 (리마인더)
  - 시계 앱 알람 설정
  - 메모 저장·검색
  - 정확한 계산
  - 현재 날짜·시간 확인
  - 앱 열기("카카오톡 열어줘"), 타이머
- 📱 폰 조작
  - 📸 사진 찍기 (갤러리 저장), "이거 뭐야?" → 찍고 바로 보고 설명, 카메라 앱 열기
  - 📞 전화·💬 문자: 연락처 이름으로 번호를 찾아 준비 (마지막 버튼은 직접)
  - 손전등, 볼륨, 음소거, 음악 재생/다음 곡, 배터리, 와이파이·블루투스 등 설정 열기
  - 지도·검색·유튜브 열기
  - 화면 조작(접근성, 선택): 다른 앱 화면을 읽고 누르고 입력하고 스크롤. 보내기·결제·삭제는 항상 먼저 확인
- 🧩 스킬: SKILL.md 지침서를 넣으면 요청에 맞을 때 젬마가 알아서 불러 씀
  - 기본 스킬: 쇼츠 대본, 블로그 글, 영어·일본어 회화, 회의록 정리
  - ⋮ 메뉴 → 스킬 관리에서 켜기/끄기, 파일이나 GitHub 주소로 추가 (AI Edge Gallery·Claude 스킬 형식 호환, 글 스킬만)
- GPU 가속 (안 되는 폰은 자동으로 CPU), 생각 모드 켜기/끄기

## 설치
1. 이 저장소의 **Releases**에서 최신 파일을 폰으로 내려받아 설치합니다.
   - `gemma-agent.apk` 기본판: 바로 설치됨 (화면 조작만 제외)
   - `gemma-agent-full.apk` 전체판: 화면 조작 포함. 접근성 권한 때문에 Google Play 프로텍트가 설치를 막으므로,
     Play 스토어 → 프로필 → Play 프로텍트 → ⚙ → "Play 프로텍트로 앱 검사"를 잠시 끄고 설치한 뒤 다시 켜세요.
   - 두 버전은 같은 앱이라 서로 덮어 설치됩니다. (처음이면 "출처를 알 수 없는 앱 설치"를 허용)
2. 앱을 열고 **Gemma 4 E2B**(RAM 8GB 이상) 또는 **E4B**(RAM 12GB 이상)를 와이파이로 내려받습니다.
   이미 `.litertlm` 파일이 있으면 "폰에서 .litertlm 파일 선택"으로 불러옵니다.

> PC용 `.gguf`(Ollama·LM Studio) 파일은 폰에서 쓸 수 없습니다.

## 고치는 곳
| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 비서의 성격·말투·규칙 | `app/src/main/java/.../llm/Prompts.kt` |
| 목소리 빠르기·높낮이 | `app/src/main/java/.../llm/Speaker.kt` (`rate`, `pitch`) |
| 도구 추가·수정 | `app/src/main/java/.../tools/AgentTools.kt` |
| 기본 스킬 | `app/src/main/assets/skills/*.md` |
| 화면 | `app/src/main/java/.../ui/` |

도구는 `@Tool` 함수 하나만 추가하면 Gemma 4가 알아서 호출합니다.

## 직접 빌드
Android Studio에서 이 폴더를 열고 실행하거나, `./gradlew assembleRelease`.
`main`에 푸시하면 GitHub Actions가 APK를 자동으로 만들어 Releases에 올립니다.
