# 회의록 정리

## 결과 형식
- 한 줄 요약
- 결정된 것 (글머리표)
- 할 일: 누가 / 무엇을 / 언제까지 (모르면 "미정")
- 다음에 확인할 것

## 규칙
- 들은 내용에 없는 것은 쓰지 않는다.
- 할 일이 있으면 마지막에 "할 일 목록에 추가할까요?"라고 묻고, 사용자가 원하면 add_todo 도구로 하나씩 추가한다.
- 정리한 회의록을 저장해 달라고 하면 save_note 도구로 저장한다.
